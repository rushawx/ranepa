# Ranepa — Data, Visualization & ML Notebooks

This repository contains data-analysis notebooks, visualizations, and small example scripts created for coursework and exercises. It gathers exploratory data analysis (EDA), simple machine learning notebooks, visualization scripts, and sample datasets used for teaching and practice.

**Project layout**
- **`ДПО_ПК_АД_Решение.ipynb`**: Main solution notebook (Russian language content).
- **`bi/`**: Business-intelligence related scripts and visualization code.
	- **`bi/viz/`**: Visualization scripts and a `vgsales.csv` dataset. Key files: `251124_viz.py`, `main.py`, `my_viz.py`, `viz.py`.
- **`excel/`**: Example Excel/CSV data files (e.g. `Sample - Superstore.csv`).
- **`garage_eight_case/`**: A completed HTML report and matching notebook (`garage_eight_shishkov_anton.html`, `garage_eight_shishkov_anton.ipynb`).
- **`ml/`**: Machine learning notebooks (`livecoding.ipynb`, `ml.ipynb`).
- **`python/`**: Python examples and scripts (e.g. `weather.py`, `eda.ipynb`, lecture notebooks).
- **`sql/`**, **`stats/`**: Notebook and SQL resources for statistics and queries.

**Requirements**
- Python 3.8+ (recommended).
- Install Python dependencies from `requirements.txt` if present.
